NullIME

언어 전환 없이 영어, 한글(두벌식), 일본어(로마자, 한자)를 그냥 입력한다. 키를 누를 때마다 가장 그럴듯한 해석이 조합 창에 보인다.

OS 입력 언어는 영어로 두는 편이 가장 잘 동작한다. 이 페이지는 물리 키(event.code)를 직접 읽는다.

wasm 불러오는 중...
  • ←→ 칸 이동
  • ↑↓ 후보 선택
  • SpaceEnter 확정 후 키 입력
  • Backspace 마지막 키 입력 취소
  • Ctrl+A/C/X/V, Ctrl+Backspace, Shift+이동 등 일반 편집 키

평가 사례 모으기

틀린 해석은 ↑↓로 바로잡은 뒤 확정하고 Ctrl+Enter(또는 아래 버튼)를 누르면 마지막 조합이 키 입력열⇥답 한 줄로 쌓인다. 답이 후보에 없으면 둘째 열을 직접 고친다. 모은 줄은 tools/nullime-dict/mixed.tsv에 붙여 넣고 nullime-dict eval --mixed로 잰다. 이 브라우저에 저장된다.
